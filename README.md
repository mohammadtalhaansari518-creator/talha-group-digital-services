TALHA GROUP Digital Services — Demo Website

CONTENTS
- index.html: responsive, mobile-friendly demo website.
- Languages: English, Hindi, Nepali.
- Service request form: saves entries only in the visitor's browser localStorage.

IMPORTANT LIMITATIONS
This is a static demo, not a live order-management system. Form submissions are NOT sent to TALHA GROUP.
There is no server, database, admin panel, payment gateway, AI integration, or customer account system.
Do not advertise it as accepting real orders until a secure backend and privacy policy are added.

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome on a phone or computer.

HOW TO PUBLISH
Upload the extracted files to a static hosting provider (for example, GitHub Pages or Netlify).
A public URL is created only after you complete hosting setup. This ZIP itself is not a public website.

For a real business launch, have a parent/guardian help review accounts, public contact details,
privacy policy, customer data handling, and any payments or contracts.
